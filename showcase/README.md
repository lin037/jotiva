# 梧桐街开放日

一套用于展示 Jotiva 的虚构项目文档。六份都是可独立阅读的 Markdown 原稿，人物、活动和时间均为演示设定。

| 适合展示 | 原稿 | 在 Jotiva 中的演示操作 |
| --- | --- | --- |
| 会议速记 | [筹备周会](notes/01-筹备周会.md) | 将文档关联到会议窗口。关掉会议窗口后，在主窗按「保留纸质签到」搜回原稿。 |
| 待办和快速切换 | [现场志愿者清单](notes/02-现场志愿者清单.md) | 勾选待办，在同一个工作窗口里切换两条便签。 |
| 长文导航 | [开放日执行手册](notes/03-开放日执行手册.md) | 展开大纲，拖宽右栏，折叠路线章节，再定位到活动结束。 |
| 表格和公式 | [雨天路线踏勘](notes/04-雨天路线踏勘.md) | 在表格添加一条候选路线，核对步行时间的算法。 |
| 代码和归档 | [报名页改版记录](notes/05-报名页改版记录.md) | 搜索 `waitlist`，把改版摘要拖到窗口生成一条新便签，再演示归档到「报名与网页」。 |
| 独立 Markdown | [一封行前信](notes/06-一封行前信.md) | 在 Finder 选择「打开方式 → Jotiva」，直接编辑原文件。 |

要展示文件树，在「工作区」点加号，选择本页旁的 `notes` 目录，展开后即可逐篇打开。也可以用 `⌘O` 只打开其中一份。工作区文件会原地保存；需要反复从相同原稿开始演示时，先复制一份 `notes` 目录。
