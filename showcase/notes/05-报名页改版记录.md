# 开放日报名页改版记录

周五更新报名页，把天气变化后仍然有效的信息放在页面上半部。用户提交报名后，确认页直接给出集合地点和时间，雨天路线另以通知补充。

## 要交付的改动

| 页面 | 改动 | 验收方式 |
| --- | --- | --- |
| 报名页 | 把开放时间和地点移到报名按钮上方 | 手机竖屏首屏可以读到两项信息 |
| 确认页 | 显示组别和完整地址 | 提交后不回首页也能找到集合点 |
| 名额已满 | 按钮进入候补流程 | 连续点击只生成一条候补记录 |

## 示例记录

```json
{
  "event": "wutong-open-day",
  "arrival": "09:30",
  "checkIn": "梧桐街社区阅览室",
  "route": "corridor",
  "registrationStatus": "waitlist"
}
```

## 上线前检查

- [x] 取消报名后可以重新提交
- [ ] 候补转为成功时，确认页显示正确的集合时间
- [ ] 改用雨天路线后，报名成功的记录仍能打开原确认页

给移动端保留足够的按钮间距。路线说明更新时看两张页面截图即可核对，参照《一封行前信》中的集合信息。
