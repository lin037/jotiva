# 现场志愿者清单

周六 09:15 在阅览室内侧集合。进门右手边是物料箱，窗下两张桌子用来签到和发观察卡。

## 开门前

- [x] 检查急救包和雨天指示牌
- [ ] 签到台
  - [ ] 摆好纸质名单，按到场顺序登记
  - [ ] 把两组颜色标签分开放
  - [ ] 给临时报名留一页空白纸
- [ ] 路线组
  - [x] 核对晴天路线的两处停留点
  - [ ] 雨天把连廊入口的指示牌转向街道

## 出发与返回

- [ ] 出发前由领队报出总人数，压队志愿者再数一遍
- [ ] 回到阅览室后收拢观察卡，给想继续画的人留座位
- [ ] 确认所有孩子都交回给同行成人

## 交接

签到名单交给林岚。观察卡可以带走，留在桌上的卡片先拍一张合照。失物写上发现的时间和地点后交阅览室前台。
