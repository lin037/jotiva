# Jotiva 快捷键

从「帮助 → 快捷键速查」或「设置 → 快捷键」可以查到当前键位。下表使用默认组合。`⌘` 是 Command，`⌥` 是 Option，`⌃` 是 Control，`⇧` 是 Shift，`↩` 是回车。

## 修改键位

点击动作旁的键位，按下新的组合，再点「保存快捷键」。例如，要更换「查找当前文档」，在「文档查找」这一组录入组合并保存，回到正文就可以试用。想取消一次录入时按 Esc。「未设置」的动作也可以分配按键。

「全局快捷键」在其他应用中也能唤起 Jotiva。速记默认使用 `⌃⇧空格`，查找便签和靠右收拢可以自行设置。macOS 或其他应用已经占用全局组合时，可以换另一组。Jotiva 提示保存成功后，新组合才生效。

文件、窗口、段落格式和表格等命令可以单独改键。设置页也列出一些位置相关的按键，例如文件树的 F2、表格里的 Tab，以及 macOS 的复制、粘贴。它们会随着当前键盘焦点切换用途。

## 文件、窗口和速记

| 在哪里用 | 默认键位 | 操作 |
| --- | --- | --- |
| Jotiva | ⌘O | 打开一份 Markdown 文件，在原位置继续编辑 |
| 主窗口 | ⌘N | 在选中的目录创建文档，填好文件名后按回车 |
| 速记浮窗 | ⌘N | 新建一张便签 |
| Jotiva | ⇧⌘N | 命名后在「其他」创建文档，并在独立窗口打开 |
| 编辑窗口 | ⌥⌘O | 在独立窗口打开当前文档 |
| 编辑窗口 | ⌘S | 立即保存 |
| 编辑窗口 | ⌘K | 查找便签和文档 |
| 主窗口 | ⌃Tab | 回到最近使用的另一份文档 |
| 主窗口 | ⌘1 / ⌘2 / ⌘3 | 聚焦正文、工作区或归档 |
| 主窗口 | ⇧⌘L | 显示或收起侧栏 |
| 便签或独立文档窗口 | ⌥⌘P | 置顶或取消置顶 |
| 已挂载的便签 | ⌘↩ | 把键盘焦点交回宿主窗口 |
| 便签或独立文档窗口 | ⌘ 加反引号 | 返回主窗口；从便签返回时会打开该文档 |
| 主窗口或独立文档窗口 | ⌘加反斜杠 | 将主窗口与独立文档并排 |
| Jotiva | ⇧⌘O | 平铺便签 |
| 编辑窗口 | ⌘W | 关闭当前标签或窗口。关闭挂载便签时会保存并解除该文档的挂载 |
| Jotiva | ⌘, / ⌘Q | 打开设置 / 保存并退出 |

## 正文、段落和表格

| 默认键位 | 操作 |
| --- | --- |
| ⌘/ | 在即时预览和源码之间切换 |
| ⌃⇧E | 切到即时预览 |
| ⌘B / ⌘I | 粗体 / 斜体 |
| ⌃⇧C / ⌃⇧K | 行内代码 / 插入或编辑链接 |
| ⌃⇧1 至 ⌃⇧6 | 将当前段落改为相应级别的标题 |
| ⌃⇧O | 折叠或展开当前标题（需开启标题折叠） |
| ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| ⌘F / ⌃⇧H | 打开文档查找 / 搜索和替换 |
| ⌃G / ⌃⇧G | 定位下一个 / 上一个匹配 |
| ⌃⇧L / ⌃⇧D | 跳转到行 / 同时选中下一个相同文本 |
| ⌃⇧P | 打开编辑器命令面板 |
| ⌘↩ / ⇧⌘↩ | 到当前块后方 / 前方继续编辑。挂载便签中 ⌘↩ 优先把焦点交回宿主 |
| Tab / ⇧Tab | 在表格中移到下一个 / 上一个单元格 |
| ↩ / ⇧↩ 或 ⌥↓ / ⌥↑ | 在表格中向下 / 向上移一个单元格 |
| ⌃⇧↓ / ⌃⇧→ | 在下方插入表格行 / 在右侧插入表格列 |
| ⌘⌥⌫ / ⇧⌘⌥⌫ | 删除当前表格行 / 列 |
| ⇧⌥⌫ | 清空当前单元格 |

在「插入」一组还可以给代码块、公式块、图片、表格和分隔线设置快捷键。正文里的列表、任务、引用和删除线也可以按自己的写作习惯分配。

## 在界面中移动

| 键盘焦点 | 键位与用途 |
| --- | --- |
| 任意 Jotiva 窗口 | F6 切到下一个区域，⇧F6 反向切换，⌥F6 从列表里选择区域。 |
| 文件树 | ↑ ↓ 选择条目，→ ← 展开或折叠，↩ 打开。F2 改名，Esc 取消改名或清除选择。选中多个文件后，⌘⌫ 打开移到废纸篓的确认。 |
| 标签栏 | ← → 打开相邻标签，Home / End 打开首尾标签，⌫ 或 Delete 关闭选中标签。 |
| 窗格分隔条 | ← → 调整宽度，Home 恢复默认。 |
| 便签查找 | ↑ ↓ 选择，↩ 打开，Page Up / Page Down 翻页，Esc 退出。 |
| 平铺视图 | 方向键移动，↩ 打开；⌘1 至 ⌘9 打开当前页对应的便签。左右键在查找框为空时生效。 |
| 窗口选择器 | 输入窗口或应用名筛选，再用 ↑ ↓ 选择，用 ↩ 确认。 |
| 正文查找框 | ↩ 查找下一项，⇧↩ 查找上一项，Esc 返回正文。 |
| 编辑器命令面板 | 输入关键字筛选，↑ ↓ 选择，↩ 执行，Esc 关闭。 |
| 编辑工具栏 | ← → 在工具间移动，Home / End 跳到首尾。 |
