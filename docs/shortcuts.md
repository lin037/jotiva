# Jotiva 快捷键

下表列的是默认快捷键。如果改过键位，可以在「设置 → 快捷键」查看当前设置。Mac 上的 ⌘、⌥、⌃、⇧ 分别表示 Command、Option、Control、Shift。Windows 和 Linux 共用一套应用内默认快捷键。

## 文件和窗口

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 打开文档 | ⌘O | Ctrl+O |
| 新建 / 新建文档窗口 | ⌘N / ⇧⌘N | Ctrl+N / Ctrl+Shift+N |
| 在独立窗口打开当前文档 | ⌥⌘O | Ctrl+Alt+O |
| 立即保存 | ⌘S | Ctrl+S |
| 查找便签和文档 | ⌘K | Ctrl+K |
| 回到最近使用的另一份文档 | ⌃Tab | Ctrl+Tab |
| 聚焦正文 / 工作区 / 归档 | ⌘1 / ⌘2 / ⌘3 | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| 显示或隐藏侧栏 | ⇧⌘L | Ctrl+Alt+L |
| 平铺便签 | ⇧⌘O | Ctrl+Shift+F8 |
| 置顶或取消置顶 | ⌥⌘P | Ctrl+Alt+P |
| 将焦点交还已挂载的窗口 | ⌘Enter | Ctrl+Enter |
| 返回主窗口 | ⌘ + 反引号 | Ctrl + 反引号 |
| 与主窗口并排 | ⌘ + 反斜杠 | Ctrl + 反斜杠 |
| 关闭标签或窗口 | ⌘W | Ctrl+W |
| 打开设置 / 保存并退出 | ⌘, / ⌘Q | Ctrl+, / Ctrl+Q |
| 从其他应用打开速记 | Control+Shift+Space | Ctrl+Shift+Space |

在 Linux 上，能否用全局快捷键打开速记取决于桌面会话。窗口挂载和自动并排也需要桌面会话支持窗口定位。在文件树里，用方向键选中文件，按 F2 改名，按 Enter 打开。移到废纸篓或回收站时，Mac 用 `⌘Backspace`，Windows 和 Linux 用 `Delete`。

## 正文和表格

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 切换即时预览和源码 | ⌘/ | Ctrl+/ |
| 粗体 / 斜体 | ⌘B / ⌘I | Ctrl+B / Ctrl+I |
| 插入行内代码 / 链接 | ⌃⇧C / ⌃⇧K | Ctrl+Shift+C / Ctrl+Shift+K |
| 改为 1 至 6 级标题 | ⌃⇧1 至 ⌃⇧6 | Ctrl+Shift+1 至 Ctrl+Shift+6 |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z | Ctrl+Z / Ctrl+Y |
| 查找正文 / 搜索和替换 | ⌘F / ⌃⇧H | Ctrl+F / Ctrl+Shift+H |
| 打开编辑器命令面板 | ⌃⇧P | Ctrl+Shift+P |
| 到行首或行末 | ⌘← / ⌘→ | Home / End |
| 到文首或文末 | ⌘↑ / ⌘↓ | Ctrl+Home / Ctrl+End |
| 移到下一个 / 上一个单元格 | Tab / Shift+Tab | Tab / Shift+Tab |
| 在下方添一行 / 在右侧添一列 | ⌃⇧↓ / ⌃⇧→ | Ctrl+Shift+↓ / Ctrl+Shift+→ |
| 删除表格行 / 列 | ⌘⌥Backspace / ⌘⌥⇧Backspace | Ctrl+Alt+Backspace / Ctrl+Alt+Shift+Backspace |

在表格里，Enter 向下移，Shift+Enter 向上移。在正文里，这两个键用来换行或续写列表，具体取决于光标的位置。

## 修改键位

在「设置 → 快捷键」按名称或组合键搜索。点当前键位，按下新的组合，再点「保存快捷键」。标为「未设置」的操作也可以分配按键。按 Esc 取消录入。如果某组按键被系统、输入法或其他软件占用，可以在这里换一组。

设置页还列出位置相关的键位，比如 F6 在正文、文件树和其他界面区域之间切换，Shift+F6 反向切换，Alt/Option+F6 打开区域列表。
