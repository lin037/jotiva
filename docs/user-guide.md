# Jotiva 使用手册

[项目首页](../README.md) · [English](en/user-guide.md)

Jotiva 能直接打开电脑里的 Markdown（`.md`、`.markdown`）和 UTF-8 文本（`.txt`）。你可以把常用文件夹加到侧栏，也可以把便签留在正在看的窗口旁。文件存回原处，换个编辑器也能接着写。

## 安装

到 GitHub Releases 下载适合电脑的安装包。 [下载 Jotiva](https://github.com/lin037/jotiva/releases)

| 平台 | 安装方法 |
| --- | --- |
| macOS 14 或更新版本 | `universal` 同时适用 Apple 芯片和 Intel。打开 DMG，把 Jotiva 拖到「应用程序」。也可以双击 PKG，或解压 ZIP 后把 Jotiva 移到「应用程序」。 |
| Windows x64 | 双击以 `-setup.exe` 结尾的文件，按提示安装。Jotiva 需要 Microsoft Edge WebView2。 |
| Linux x86_64 | 在 Ubuntu 24.04 上，可以运行 `sudo apt install ./文件名.deb`。如果下载的是 AppImage，在文件所在目录运行 `chmod +x ./文件名.AppImage`，再打开它。 |

0.1.1 的 macOS 下载包使用临时签名，Windows 安装包未签名。系统可能提示验证发布者。Linux 上，窗口管理与文件菜单的行为会随桌面环境变化。 [Tauri AppImage 说明](https://v2.tauri.app/distribute/appimage/)

## 打开一份文档

1. 在 Jotiva 按 `⌘O`（macOS）或 `Ctrl+O`（Windows、Linux），打开电脑里的文档。手边没有 Markdown 文件的话，可以先下载这份示例笔记。 [HelloJotiva.md](HelloJotiva.md)
2. 在即时预览里，可以直接勾选待办，或者点进表格改内容。按 `⌘/` 或 `Ctrl+/` 查看 Markdown 源码，再按一次切回来。纯文本文件直接显示正文。
3. 停一会儿不输入，Jotiva 会自动保存。想马上保存，就按 `⌘S` 或 `Ctrl+S`。窗口底部会显示保存状态和文件位置。读长文时，可以点右侧大纲里的标题跳过去。
4. 用侧栏的「添加工作区文件夹」把常用目录加进来，之后可以用标签切换文档。要对照两份文件，在侧栏右键选「在新窗口打开」。

单击侧栏文件会打开斜体的预览标签。继续浏览会替换这一个标签，开始编辑或双击文件、双击标签即可保留。也可在标签右键菜单选「保留标签」。在「设置 → 编辑器」关闭「单击文件时使用预览标签」，每个文件就会单独保留。

## 在另一个应用旁写便签

| 平台 | 窗口挂载 |
| --- | --- |
| macOS | 在「设置 → 窗口关联」授权辅助功能，允许 Jotiva 识别其他应用的窗口。 |
| Windows | 可以从 Jotiva 选目标窗口，也可以把文档拖到目标窗口。 |
| Linux | 兼容 EWMH 的 X11 会话支持挂载。原生 Wayland 可使用独立便签。全局按键能否触发取决于桌面会话。 |

要在浏览器旁记一笔，先点浏览器窗口，再按 `Control+Shift+Space` 新建一张便签。再次按键或点便签右上角「更多 → 新建便签」，都会再开一张。点原便签或它的摘要可以继续写。写完按 `⌘Enter`（macOS）或 `Ctrl+Enter`（Windows、Linux），就能回到刚才的窗口继续用键盘。按 `Esc` 可以把便签收成一条摘要。原来的窗口关掉后，还可以在「待重新挂载」里找到便签，或用全局搜索找回来。

同一个应用开了多个窗口时，可以给每扇窗口各留一张便签。也可以在侧栏右键点击已有文档，选「挂载到窗口…」，再按提示切到要挂载的窗口。想让同一张便签跨窗口显示，就点图钉置顶。想回到大窗口写，选「在主窗口编辑」。关闭已挂载的便签时，Jotiva 会保存内容并解除挂载。

**macOS 已打开辅助功能开关，仍然提示授权？** 退出 Jotiva 并从「应用程序」重新打开。如果刚替换过应用，展开提示里的「已打开开关，仍提示未授权？」，核对正在运行的是哪一份 Jotiva，再到「系统设置 → 隐私与安全性 → 辅助功能」更新该条目。

## 整理和找回文件

- 从工作区移除文件夹，只会撤掉侧栏里的入口。把文档拖到工作区的另一个文件夹，则会移动磁盘上的文件。
- 新建的速记保存后，在「归档 → 其他」里找。想把便签放到自己建的归档目录，可以从编辑器底部的文件路径菜单移动。
- 如果另一个应用也改了同一份文档，选「另存编辑并重载」。Jotiva 会把你刚写的内容存到「其他」，再打开原文件。如果暂时读不到原文件，Jotiva 会尝试显示上次保存的内容。

想备份速记，可以用状态栏或右键菜单在文件管理器里找到它，也可以直接打开下面的目录。

| 平台 | 默认速记目录 |
| --- | --- |
| macOS | `~/Library/Application Support/io.github.lin037.jot.desktop/notes/其他/` |
| Windows | `%APPDATA%\io.github.lin037.jot.desktop\notes\其他\` |
| Linux | `~/.local/share/io.github.lin037.jot.desktop/notes/其他/`。如果设置了 `XDG_DATA_HOME`，用它的值替换 `~/.local/share`。 |

### 让 Jev 推荐归档位置

Jev 可以建议把便签放到哪个目录，默认关闭。启用后，点「用 Jev 归档」才会把这份便签的前 6000 个字符，以及候选目录的名称和说明，发给你配置的服务。确认建议后，文档才会移动。

1. 在「设置 → 归档」选「基础地址」或「完整接口地址」，再填入服务商提供的地址。按需填写模型名称。远程服务需要 HTTPS。本机服务可用 `http://127.0.0.1:端口` 或 `http://[::1]:端口`。
2. 如果页面提示此地址还没有密钥，点「配置密钥…」，在系统弹窗中输入。密钥分别存入 macOS 钥匙串、Windows 凭据管理器或 Linux 系统密钥环。Linux 需要 Secret Service、`secret-tool` 和 `zenity`。勾选「允许 Jev 归档」，再点「保存设置」。
3. 在归档目录的设置里勾选「参与 Jev 分类」，写一句这个目录用来放什么。回到「其他」，打开一张便签，点「用 Jev 归档」看建议。便签太短或没有匹配时，也可以自己选目录。

在工作区或归档目录新建文档时，空文件会立即保存，文件树会选中名称供你输入。点击其他位置或按 Enter 即可保存名称。遇到重名，Jotiva 会在扩展名前追加序号，并显示最终文件名。

搜索结果会在滚动时继续加载。按 ↓ 或 Page Down 可以进入下一批，按 ↑ 可以回看已经加载的结果。右击标签可复制文档正文、制作文件副本、在新窗口打开，或关闭左侧、右侧及其他标签。

## 使用内置终端

编辑文件时，按 **Ctrl + Shift + 反引号** 会回到从该文档打开且最近使用的终端。首次使用或原会话已结束时，会在文件所在目录新建终端。从工作区文件树、归档目录或文档标签的右键菜单选择「在此处新建终端」，可指定启动位置。没有已保存的文档时，终端从默认归档目录「其他」启动。

标题栏的终端按钮可收起面板或回到上次使用的会话。点击面板中的「＋」可再开一个终端，多个会话列在终端右侧，点击可切换，行内的垃圾桶可单独结束该会话。切换文档时终端保持原样，关闭文档后命令也会继续运行。拖动面板上边缘可调整高度。

将文件或文档标签拖到终端，可以在光标处插入已转义的文件路径，按 Enter 后才执行。脚本可以读取环境变量 `JOTIVA_INBOX_DIR`，将生成或同步的文档放进「其他」归档目录。在 PowerShell 中使用 `$env:JOTIVA_INBOX_DIR`，在 Bash 或 Zsh 中使用 `"$JOTIVA_INBOX_DIR"`。「结束终端」只关闭当前会话。关闭主窗口或退出应用时，如果还有终端在运行，应用会请你确认。

## 按自己的习惯写


在「设置 → 外观 → 界面语言」选择简体中文或 English，已打开的窗口会立即更新。

按 `⌘,`（macOS）或 `Ctrl+,`（Windows、Linux）打开设置。在「外观」里可以换主题、改字号，或导入自己的 CSS。想改快捷键，就在「快捷键」里按名称或组合键搜索，点当前键位，按下新组合，再保存。 [主题说明](themes.md)

[查看三端快捷键](shortcuts.md)


在「设置 → 外观 → 界面主题」可切换默认、墨与钢和 Material。打开的文档和终端会同步换色，已导入的 CSS 继续覆盖主题。

## 软件更新

支持内置更新的安装包会在启动时和运行期间每六小时检查一次。发现新版本时，点主窗口的更新按钮，或进入「设置 → 软件更新」。点「安装更新并重启」后，Jotiva 会下载、验证签名并保存文档。如果窗口中有终端正在运行，可以取消退出。使用 0.1.1 的用户首次升级需要手动安装，Debian 包通过系统包管理器更新。
