# Jotiva 使用手册

[项目首页](../README.md) · [快捷键](shortcuts.md) · [主题与排版](themes.md) · [English](en/user-guide.md)

Jotiva 直接读写你本机上的 Markdown（`.md`、`.markdown`）和 UTF-8 纯文本（`.txt`）。围绕日常高频场景，它重点解决五件事：
- **便签速记**：在正在用的窗口旁随手贴便签，切走自动隐藏，切回原窗口自动浮现；
- **Jev 智能管理**：随手记先落盘，事后按笔记内容与目录说明智能推荐归属文件夹；
- **脱离鼠标**：从唤起便签、交还焦点、搜索回跳到面板切换、表格编辑，全流程纯键盘完成；
- **即时排版渲染**：光标所在处展开语法，移开即恢复排版，公式、图表、表格原位渲染与编辑；
- **目录级图片管理**：按文件夹定制存图规则（跟随文档、共用目录或上传图床），子目录自动继承。

所有文件均保存在本地真实目录中，随时可以用 Git 或其他编辑器继续处理。

## 安装

前往 [GitHub Releases](https://github.com/lin037/jotiva/releases) 下载对应平台的安装包：

| 平台 | 安装方式 |
| --- | --- |
| **macOS 14+** | `universal` 安装包同时支持 Apple 芯片与 Intel。打开 `.dmg` 将 Jotiva 拖入「应用程序」，或使用 `.pkg` 安装包 / `.zip` 解压后移入「应用程序」。 |
| **Windows x64** | 运行 `-setup.exe` 安装程序按提示完成安装（需要 Microsoft Edge WebView2）。 |
| **Linux x86_64** | Debian / Ubuntu 可运行 `sudo apt install ./文件名.deb`；使用 AppImage 时先赋予执行权限 `chmod +x ./文件名.AppImage` 再启动。 |

> [!NOTE]
> 未签名或未经公证的安装包，首次打开时可能会触发系统安全提示。手册按当前源码编写，安装包的功能以对应版本为准。

## 一、便签速记：在工作窗口旁随手记

当你正在浏览器查资料、开会或调试代码时，不用来回切换窗口，直接唤起一张跟着当前窗口走的便签：

1. **贴在当前窗口旁**：点击你要参考的目标窗口，按下全局快捷键 **`Control+Shift+Space`** 新建便签。同一软件的不同窗口可以挂不同便签，单个窗口也能挂多张。
2. **写完秒回原窗口（脱离鼠标）**：在已挂载便签里写完一笔后，按 **`⌘Enter`**（macOS）或 **`Ctrl+Enter`**（Windows / Linux），键盘焦点会立刻交还给原来的应用，继续浏览或打字。
3. **跟窗显隐与置顶**：按 **`Esc`** 可把便签折成紧凑的单行摘要；点击右上角图钉可**跨窗置顶**。切到其他应用时，未置顶的挂载便签会自动隐藏，切回原窗口时重新出现。

### 把已有文档挂到窗口旁，或切回主窗口深写
- **挂载已有文档**：在主窗口侧栏右击任意文档，选「**挂载到窗口…**」，再切到目标窗口即可（也可点击「**从列表选择…**」，Windows 还支持直接把文档拖到目标窗口上挂载）。
- **在主窗口继续写**：在便签菜单里点击「**在主窗口编辑**」，同一份本地文件会直接在主窗口打开，方便配合大纲、表格和终端写成长文。

### 从笔记找回当时的工作现场
在 Jotiva 中按 **`⌘K`**（macOS）或 **`Ctrl+K`** 打开全局搜索：
- 搜索结果按 **「当前窗口 / 其他窗口便签 / 文档」** 分组（在主窗口搜索时，挂载便签归为「已挂载便签」）。选中一张已挂载便签，Jotiva 会尝试直接带你回到它所关联的那个窗口。
- 已登记便签支持按正文内容搜索；工作区和归档目录里尚未登记的文档支持按文件名查找。
- 如果原窗口已经关闭，便签不会丢失，可以在「**待重新挂载**」列表中找到它，或通过搜索找回并重新挂到新窗口。

<details>
<summary>各平台窗口挂载说明与 macOS 权限排查</summary>

- **macOS**：需要在「设置 → 窗口关联」中授权**辅助功能**权限，Jotiva 才能识别其他应用的窗口。若你在系统设置中已打开开关却仍提示未授权，请退出 Jotiva 并从「应用程序」重新打开；如果刚覆盖安装过新版，请在「系统设置 → 隐私与安全性 → 辅助功能」中移除旧条目后再重新添加当前应用。
- **Windows**：支持在列表选择目标窗口，或将标签/文档直接拖到目标窗口完成挂载。
- **Linux**：在兼容 EWMH 的 X11 会话中支持窗口挂载；原生 Wayland 会话可使用独立便签。全局快捷键的触发支持取决于所使用的桌面环境。

</details>

## 二、即时渲染与长文写作

按 **`⌘O`** / **`Ctrl+O`** 可直接打开本机文件；手边没有现成文件时，可以先打开 [HelloJotiva.md](HelloJotiva.md) 体验。

### 原位即时渲染与源码切换
- **所见即所得的原位编辑**：在即时预览模式下，只有光标进入普通段落时才展开 Markdown 标记，移开立刻恢复排版。点击表格直接修改单元格，勾选待办方框直接写回源文件。
- **技术写作开箱即用**：同一篇 `.md` 原生支持行内与块级 LaTeX 公式、代码块（可在设置中切换自动换行或横向滚动）、自动跟随浅/深色主题的 Mermaid 图表（流程图、时序图、甘特图等）、表格与图片。
- **一键切换源码**：随时按 **`⌘/`** / **`Ctrl+/`** 切换到完整 Markdown 源码，再按一次切回即时预览。

### 脱离鼠标的导航、多标签与多窗口
- **全键盘切换区域**：按 **`F6`** / **`Shift+F6`**（或 `⌘1` 正文、`⌘2` 工作区、`⌘3` 归档）在编辑器、文件树与大纲之间快速跳转；在表格内用 `Tab` / `Enter` 和快捷键移动及增删行列（完整键位见 [快捷键参考](shortcuts.md)）。
- **工作区侧栏**：点击「**添加工作区文件夹…**」把常用代码库、博客或笔记目录加到侧栏。新建文档时，空文件会立即落盘并在侧栏选中名称供你输入，重名自动追加序号。
- **大纲与章节折叠**：长文可通过右侧「**文档大纲**」跳转章节，也可按 `⌃⇧O` / `Ctrl+Shift+O` 折叠或展开当前标题下的内容。
- **预览标签与多窗口并排**：单击侧栏文件默认以斜体**预览标签**打开，浏览其他文件时自动复用；开始编辑、双击文件或右键选「**保留标签**」即可固定保留（也可在「设置 → 编辑选项」关闭预览标签）。右键文件或标签选「**在新窗口打开**」，可开启独立文档窗并排对照。

### 自动保存与防冲突合并
停止输入片刻后 Jotiva 会自动保存，也可按 **`⌘S`** / **`Ctrl+S`** 立即保存。如果同一份文件同时在多个窗口中被编辑：
- 修改不同区域时，Jotiva 会自动尝试合并；
- 如果磁盘文件已被外部应用修改或存在重叠冲突，可点击「**另存编辑并重载**」，先把当前窗口未保存的改动安全存进「归档 → 其他」，再重新加载磁盘原文，避免内容丢失。

## 三、Jev 智能管理与目录归档

Jotiva 把「正在维护的工程目录」和「随手记下的临时想法」分开管理，让你在记录时没有分类负担：
- **工作区（Workspace）**：存放你持续维护的代码仓库、博客或项目文档。从工作区移除文件夹**只会撤掉侧栏入口，不会删除磁盘文件**；在侧栏拖拽文件则会实际移动磁盘位置。
- **归档（Archive）**：新建的随手便签都会先落入「**归档 → 其他**」。准备整理时，既可以通过底部状态栏路径菜单或右键「**移到归档目录…**」手动移入目标文件夹，也可以交给 **Jev 智能归档**。

### 用 Jev 智能推荐归档目录（可选）
Jev 归档**默认关闭**，开启后也只会在你主动点击「**用 Jev 归档**」时触发：

1. 在「**设置 → 文档归档**」选择服务地址类型（基础地址或完整接口地址），填写服务商或自建服务的 URL 与模型名称（远程服务须使用 HTTPS，本机调试可用 `127.0.0.1` 或 `[::1]`）。
2. 点击「**配置密钥…**」在系统弹窗中输入 API 密钥，密钥安全保存在系统凭据库（macOS 钥匙串 / Windows 凭据管理器 / Linux 系统密钥环）中。勾选「**允许 Jev 归档**」并保存。
3. 在侧栏右击已导入的归档目录，打开「**归档目录设置…**」，填写易读的显示名称与**用途说明**（例如「存放后端接口排查与数据库慢查询记录」），并勾选「**参与 Jev 分类**」。
4. 打开「其他」里的已保存便签并点击「**用 Jev 归档**」（正文需至少包含 20 个文字或数字）。Jotiva 会发送正文摘录（去掉首尾空白后最多 6,000 字符）以及候选目录的名称与说明，得出匹配建议后**由你确认**再移动文件。

<details>
<summary>默认速记文件夹磁盘路径</summary>

如果想直接备份「归档 → 其他」中的速记文件，可以在状态栏或右键菜单中选择在文件管理器中显示，或直接打开对应系统的目录：
- **macOS**：`~/Library/Application Support/io.github.lin037.jot.desktop/notes/其他/`
- **Windows**：`%APPDATA%\io.github.lin037.jot.desktop\notes\其他\`
- **Linux**：`~/.local/share/io.github.lin037.jot.desktop/notes/其他/`（若设置了 `XDG_DATA_HOME`，则替换 `~/.local/share`）

</details>

## 四、按目录管理图片

粘贴截图或从工具栏插入本地图片时，Jotiva 会按照当前文档所在目录的规则自动存图并生成 Markdown 链接。可在 **「设置 → 图片管理」** 配置全局默认规则，或右击任意文件夹选择 **「图片管理…」** 为该目录单独定制：

| 保存方式 | 适用场景 | 典型配置示例 |
| --- | --- | --- |
| **跟随文档**（默认） | 每篇文档把图片存到同级子目录（默认 `_assets`），移动或复制文档时带着图片子目录一起走即可。 | 实验记录目录设为 `images`，会议纪要目录设为 `media/screenshots`。 |
| **固定目录** | 同一项目或博客的所有文档共用一个图片目录，支持勾选「相对于此文件夹」生成相对路径。 | 在博客根目录的「**图片管理…**」设为「固定目录 → 相对于此文件夹」并填 `../assets`，所有文章粘贴图片时自动生成相对引用。 |
| **HTTP 上传** | 粘贴图片时自动上传到图床或上传网关，并在正文中直接插入返回的在线 URL。 | 适合需要公开发布的博客文章或在线分享文档。 |

- **子目录自动继承**：子目录会自动沿用最近一层上级目录的规则；没有任何上级规则时回退到全局默认。在文件夹的「**图片管理… → 目录规则**」中选择「**恢复继承**」即可撤掉单独配置。
- **自动编号与体积压缩**：本地存图支持按文档名再建子目录，重名文件自动追加序号；可开启「自动压缩静态图片」，在不改变分辨率的前提下压缩静态 PNG / JPEG（仅在压缩后更小时采用，动图保持原样，单张图片上限 32 MiB）。

<details>
<summary>配置 HTTP 图床上传参数与 macOS 本地选图提示</summary>

- **HTTP 上传参数**：接口需接收 `POST multipart/form-data` 请求并返回 JSON。例如服务接收字段为 `file`，返回 `{"data":{"url":"https://cdn.example.com/photo.png"}}`，在设置中分别填入 `file` 与 JSON Pointer `/data/url` 即可；如需鉴权可勾选「使用 Bearer 密钥」并在系统凭据中配置密钥。

</details>

## 五、从当前文档唤出内置终端

写作时如果需要预览静态博客、跑校验脚本或执行 Git 命令，无需切出 Jotiva：
- **一键定位到当前目录**：在主窗口按 **`` Ctrl+Shift+` ``**（macOS 与 Windows / Linux 通用），即可打开或切回当前文档所在目录的终端会话；也可在侧栏目录或文档标签右键选择「**在此处新建终端**」。
- **切换文档不断连**：切换标签页或关闭文档时，后台终端进程继续运行；点击终端标题栏「`＋`」可多开会话，在右侧列表切换，右键或按 `F2` 可重命名会话。
- **拖拽路径与收件箱环境变量**：把文件或文档标签拖进终端，会在光标处自动插入已转义的路径。外部脚本可读取环境变量 `JOTIVA_INBOX_DIR`（Bash/Zsh 用 `"$JOTIVA_INBOX_DIR"`，PowerShell 用 `$env:JOTIVA_INBOX_DIR`），把脚本生成的 `.md` 直接送进「归档 → 其他」。

## 六、外观、语言、快捷键与更新

- **界面语言**：按 **`⌘,`** / **`Ctrl+,`** 打开设置，在「**界面外观 → 界面语言**」切换「简体中文」或「English」，所有已打开窗口立即生效。
- **主题与排版解耦**：内置与导入的 `.css` 主题只管配色，你设好的字号、字体、H1–H6 比例、横线稿纸及全局 CSS 微调独立保存，互不覆盖。详见 [外观与主题](themes.md)。
- **快捷键定制**：可在「**设置 → 快捷键**」搜索并修改组合键，默认键位表见 [快捷键参考](shortcuts.md)。
- **软件更新**：支持自动更新的安装包会在启动时及每 6 小时检查新版本，也可在「**设置 → 软件更新**」手动检查安装（Linux `.deb` 包通过下载并安装新版更新）。更新重启前会自动保存已打开的文档；若有终端会话正在运行，会先弹窗请你确认。
