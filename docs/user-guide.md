# Jotiva 使用手册

[项目首页](../README.md) · [English](en/user-guide.md)

Jotiva 是一款 macOS Markdown 编辑器。你可以直接打开电脑里的文档，也可以在开会或查资料时把一张便签留在对应的窗口旁。Markdown 文件通常以 `.md` 结尾。即使换一个编辑器，也能打开这些文件继续写。

## 安装和打开

Jotiva 需要 macOS 14 或更新版本。`universal` 安装包适用于 Apple 芯片和 Intel Mac。`aarch64` 安装包适用于 Apple 芯片。下载后任选一种安装方式。 [下载 Jotiva](https://github.com/lin037/jotiva/releases/latest)

- **拖拽安装（DMG）**。打开 `.dmg`，按箭头把 Jotiva 拖到右边的「应用程序」。等复制完成后推出磁盘映像。
- **用系统安装器安装（PKG）**。双击 `.pkg`，可以仅为自己安装，也可以为这台 Mac 的所有用户安装。仅为自己安装时，Jotiva 在个人主目录的「应用程序」里。
- **解压安装（ZIP）**。解压 `.zip`，将 `Jotiva.app` 移到「应用程序」。

从「应用程序」打开 Jotiva，按 `⌘O` 选一份 Markdown 文档，也可以在 Finder 右键文件，选择「打开方式 → Jotiva」。

## 打开一份文档并开始写

1. 用 `⌘O` 打开文件。停下输入后，Jotiva 会自动保存。`⌘S` 可以立即保存。底部显示文件位置、字符数和保存状态。
2. 在即时预览里，标题、任务和表格会带着格式显示，正文仍然可以直接编辑。按 `⌘/` 可以切到源码，再按一次回到即时预览。
3. 拖入几份 Markdown 就能用标签切换，`⌃Tab` 回到最近用过的另一份。要对照两份材料，在文件上右键选「在新窗口打开」，或者按 `⌥⌘O` 独立打开当前文档。
4. 长文可以展开大纲，点一个标题跳到对应位置。`⌘F` 查当前正文，`⌘K` 查找便签和文档。

可以复制一份[梧桐街开放日示例](../showcase/README.md)，试着勾掉几条待办、修改表格，再回 Finder 看原文件。

## 在另一个应用旁速记

1. 先点一下要跟随的窗口，例如会议或浏览器。按 `⌃⇧空格` 开始写。Jotiva 需要 macOS 的辅助功能权限来识别窗口。你也可以提前在 Jotiva 的「设置 → 窗口关联」里点「授权辅助功能」，在系统设置中打开 Jotiva 的开关。
2. 写完按 `⌘↩`，键盘回到原来的窗口。按 `Esc` 可以把便签折叠成摘要。需要跨应用看同一张便签时，可以点图钉置顶。
3. 切回原窗口时便签会跟着回来。原窗口关闭后，从主窗口的「待重新挂载」或用 `⌘K` 找回文档。Jotiva 能唯一识别重新打开的原窗口时会恢复关联，也可以手动选一个新窗口。
4. 用红色关闭按钮或 `⌘W` 可以保存并关闭便签，同时解除本篇挂载。要留着关联并在大窗口续写，选「在主窗口编辑」。

想把已有资料放到另一个应用旁，在主窗右键文件，选「挂载到窗口」。如果还没授权，点「打开辅助功能设置」，在 macOS 里打开 Jotiva 的开关，再回到 Jotiva 选择目标窗口。已经在侧栏登记过的窗口也可以直接接收文件拖放。文档会留在原来的位置。

辅助功能权限可以随时在系统设置中关闭。普通 Markdown 编辑仍可使用。速记键被其他应用占用时，可以从菜单栏打开「设置 → 快捷键」重新录入。

**已经打开开关，却仍提示未授权？** 如果刚刚替换过 Jotiva，先按 `⌘Q` 退出，从「应用程序」重新打开。展开授权提示里的「已打开开关，仍提示未授权？」，点「在 Finder 中显示这份 Jotiva」核对位置。如果系统列表里勾选的是旧副本，在「隐私与安全性 → 辅助功能」中选中旧条目，点减号移除，再点加号选中刚才找到的应用并打开开关。

## 整理文件和便签

| 你想做的事 | 在哪里操作 |
| --- | --- |
| 浏览几个项目的文件 | 在侧栏「工作区」加入目录，逐级展开。移除工作区入口只取消登记。 |
| 在指定目录创建 Markdown | 选中目录按 `⌘N`，填文件名后回车。 |
| 整理临时便签 | 新速记保存后会出现在「归档 → 其他」。可以导入自己的归档目录，再从正文底部的路径菜单移动便签。 |
| 改名、制作副本或在 Finder 显示 | 右键文件，或选中后用 `F2` 改名。工作区拖放会移动磁盘上的文件。 |
| 备份便签 | 在「归档 → 其他」展开条目，从状态栏或右键菜单在 Finder 中找到保存位置。 |

遇到保存冲突时，点击「另存编辑并重载」。Jotiva 会把刚才写的内容保存到「归档 → 其他」，然后尝试重新打开原文件。

如果原文件已移走或所在磁盘暂时断开，从 Jotiva 中打开之前保存过的文档时，可能看到「原文件当前不可用，显示上次保存的内容」。可以接回磁盘再打开，也可以点「另存编辑并重载」，把这份内容留在「其他」。

### 默认便签存在哪里

打开 Finder，按 `⇧⌘G`，粘贴下面的路径并回车，就能看到「其他」里的 Markdown 文件。

```text
~/Library/Application Support/io.github.lin037.jot.desktop/notes/其他/
```

这是 Jotiva 的应用数据目录，正常重启或系统清理临时文件时，便签会保留。外观、快捷键、工作区和归档设置在上方路径的 `io.github.lin037.jot.desktop` 目录里。用「归档」导入的目录由你自己选择，建议放在平时备份文档的位置。Jotiva 会拒绝把系统临时目录设为归档目标。

### 用 Jev 推荐归档位置

Jev 可以根据便签内容帮你选目录，默认关闭。你可以使用服务商给的地址，也可以连接自己的 Jev 兼容服务。远程服务使用 HTTPS。如果服务运行在这台 Mac 上，可填写 `http://127.0.0.1:8080` 或 `http://[::1]:8080`，将 `8080` 换成服务的端口。

1. 打开「设置 → 归档」。服务商给的是基础地址时，选「基础地址」，填入服务地址，保留其中的路径前缀。已有完整的请求地址时，选「完整接口地址」，照原样填写。「模型名称」默认是 `jev-latest`，自建服务可以填写自己的模型名。
2. 看同一页的「API 密钥」，这里会显示当前地址是否已配置密钥。点「配置密钥」，核对弹窗中的请求地址后输入密钥。密钥保存在 macOS 钥匙串，之后可以在这里更换或移除。勾选「允许 Jev 归档」，点「保存设置」保存开关、地址和模型。你也可以先保存设置，以后再补密钥。
3. 在主窗的「归档」添加或编辑目录，勾选「参与 Jev 分类」。给容易混淆的目录补一句说明，例如「客户访谈」收原始记录，「产品需求」收已经确定的改动。
4. 打开「其他」中的一张便签，点编辑器底部或「文件」菜单中的「用 Jev 归档」。此时 Jotiva 会将正文开头最多 6000 个字符、参与分类的目录名称和说明发送到你填写的服务。新建便签、打字和普通保存都在本机完成。少于 20 个文字或数字时，仍可自己选目录移动。
5. 看过建议后，点「移到」按钮确认。如果想改天再整理，直接取消。没有匹配、网络出错或取消时，便签都留在「其他」。

## 调整写作环境

用 `⌘,` 打开设置。「外观」可以切换浅色、深色和字号，「编辑器」可以调整正文字体、标题大小、代码折行和工具栏。想用自己的 CSS，可以在「外观」导入，也可以从系统「主题」菜单关闭。

到「设置 → 快捷键」搜索操作名称，例如「加粗」。点当前键位，按下新组合，再点「保存快捷键」。同一页也列出了系统编辑和各个界面的导航键。「帮助 → 快捷键速查」可以直接打开这一页。
