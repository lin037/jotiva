# 安全政策（Security Policy）

如果你发现了可能导致本地文件丢失、凭据/密钥泄露或权限绕过的安全问题，**请勿在公开 Issue 或讨论区披露**，请通过 GitHub Security Advisories 私下联系维护者：

- **私下提交报告**：[GitHub Security Advisory](https://github.com/lin037/jotiva/security/advisories/new)

提交时请尽量附带：
1. 受影响的 Jotiva 版本与操作系统环境。
2. 最小复现步骤与潜在影响范围。
3. 脱敏后的测试文档或日志（请勿包含真实个人笔记或密钥）。

---

If you discover a security vulnerability that could cause data loss, credential exposure, or permission bypass, please report it privately via [GitHub Security Advisories](https://github.com/lin037/jotiva/security/advisories/new) rather than opening a public issue. Include the affected version, OS, minimal reproduction steps, and sanitized logs or sample files.
